## 📌 Sobre o Projeto

Uma landing page de alta conversão desenvolvida sob medida para o pet shop **Nutri-Cão Rações**. O projeto foi desenhado com foco total na experiência do usuário (UI/UX) e na captação de clientes para a loja física e delivery local.

O site funciona como uma vitrine digital interativa, onde o cliente pode pesquisar produtos em tempo real, ver avaliações reais do Google, verificar a localização no mapa e ser direcionado automaticamente para o atendimento via WhatsApp com mensagens pré-configuradas.

## ✨ Funcionalidades Principais

- **Catálogo Interativo:** Sistema de busca em tempo real no front-end para filtrar produtos.
- **Smart WhatsApp Fallback:** Se um produto pesquisado não for encontrado na vitrine, o site gera um botão dinâmico que envia o termo pesquisado direto para o WhatsApp da loja para consultar a disponibilidade.
- **Navegação Fluida (Smooth Scroll):** Âncoras no menu principal que deslizam suavemente até as seções específicas.
- **Carrossel Infinito:** Exibição das marcas parceiras em um banner rotativo animado.
- **Integração com Google Maps:** Mapa embutido (embed) e botão direto de "Como Chegar" para traçar rotas via GPS.
- **Prova Social:** Exibição de avaliações reais de clientes com a nota do Google.
- **UX Otimizada:** Botão "Voltar ao Topo" flutuante e design 100% responsivo (Mobile-First).

## 🛠️ Tecnologias Utilizadas

- **[Next.js](https://nextjs.org/)** - Framework React para renderização e estrutura do projeto.
- **[React](https://reactjs.org/)** - Biblioteca JavaScript para construção de interfaces de usuário.
- **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS Utility-first para estilização rápida e responsiva.
- **[Lucide React](https://lucide.dev/)** - Biblioteca de ícones modernos e leves.
- **[Vercel](https://vercel.com/)** - Plataforma para hospedagem e deploy contínuo (CI/CD).

## 🚀 Como Executar o Projeto Localmente

1. Clone este repositório:

```bash
git clone [https://github.com/kauanssantana/nutri-cao-racoes.git](https://github.com/kauanssantana/nutri-cao-racoes.git)
```

2. Acesse a pasta do projeto:

```bash
cd nutri-cao-racoes
```

3. Instale as dependências:

```bash
npm install
# ou
yarn install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
```

5. Abra o navegador e acesse: `http://localhost:3000`
